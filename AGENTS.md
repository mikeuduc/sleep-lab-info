# Public information site

- This repository contains only a public informational website for a private
  test project for one person.
- Keep public descriptions general. Do not introduce specific data-source
  combinations, detailed features, analysis methods or future project plans.
- Keep privacy disclosures accurate about the data categories and handling.
- Never add personal records, credentials or private application files.
- Edit the HTML and CSS directly here. There is no separate source copy or
  build step. Publishing uses GitHub Pages from the root of `main`.
- Preserve relative page links and the `noindex, nofollow` metadata.
