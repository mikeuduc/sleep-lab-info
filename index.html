One-person test project · In development

A personal sleep project.

SleepLab is a private test project for one person, using personal sleep information and other authorized data to explore patterns and potential ways to improve sleep.

About this project

The project is in early development and is limited to the owner's personal use. This website provides basic project information and policies.

Personal records and analysis are kept in the owner's local workspace. The project does not offer public accounts or a hosted analysis service.

Oura access

Oura records are accessed only after the account owner authorizes the integration. Access is limited to the permissions granted by the owner. The privacy policy describes the information used.

Project status

SleepLab is an experimental personal tool, not a medical device or a source of medical advice. It is independently developed and is not an official Oura product.
